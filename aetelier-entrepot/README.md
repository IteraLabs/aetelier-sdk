# aetelier-entrepot

Object-store transport for aetelier collectors: signed S3 access, listing,
retrieval, and archive codecs.

Placeholder README. The module map and public surface are documented in the
crate rustdoc (`cargo doc -p aetelier-entrepot --open`).

The `entrepot` binary that drives archive replay is declared by the
`aetelier-sdk` package, not by this crate.
